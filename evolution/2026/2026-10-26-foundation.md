# 建立 Agent Craft

日期：2026-10-26

## 背景

过去关于 Agent 的使用经验分散在全局 `AGENTS.md`、技能仓库、个人文章和临时对话中。
这些内容分别回答不同问题，但缺少一个统一入口，也无法清楚看到判断随时间发生的变化。

## 本次判断

新建一个独立仓库，集中保存：

- 本人稳定使用习惯
- 已经验证的重复工作流
- 使用实验和重要取舍
- 可视化、可追溯的思想演进

仓库采用“原则 / 工作流 / 实验与决策 / 演进”四层结构。稳定结论与历史过程分开维护，
避免把所有内容都写成时间线，也避免只留下最后结论。

## 当前边界

- 仓库优先作为私人知识库，经整理后再选取适合公开的内容。
- 不直接同步整个 `.codex/` 目录，也不保存会话、日志或凭据。
- 第一版使用 Markdown 与 Mermaid，保证 GitHub 上可直接阅读。

## 待验证

- 是否需要把全局 `AGENTS.md` 迁入仓库并建立本地同步流程
- 时间线在条目增多后是否仍适合 Mermaid，还是需要独立网页
- 公开版本与私人版本的边界和整理成本
